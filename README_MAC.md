# Dentistry Scheduler — Mac Setup

## First-time setup

Install Homebrew from [brew.sh](https://brew.sh), then clone the repository:

```bash
git clone https://github.com/LeonardN516/Dental-student-application-.git
cd Dentistry_scheduler
bash setup_mac.sh
```

## Start the application

```bash
cd Dentistry_scheduler
bash start_mac.sh
```

The browser opens automatically. Press `Control+C` in Terminal to stop the application.

## Pull updates

```bash
cd Dentistry_scheduler
git pull origin main
bash setup_mac.sh
bash start_mac.sh
```

## Open pgAdmin

```bash
open -a "pgAdmin 4"
```
